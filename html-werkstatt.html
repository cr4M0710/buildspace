Station 1 von 5 · 3 Minuten

Was eine HTML-Datei ist

Jede Webseite besteht aus HTML. Anders als ein Arbeitsblatt kann sie reagieren: Antworten prüfen, mitrechnen, Karten umdrehen, Zeit stoppen. Drei Sprachen arbeiten dabei zusammen.

HTML

Was auf der Seite steht

Überschriften, Texte, Bilder, Knöpfe, Eingabefelder. Wie das Gerüst eines Regals.

CSS

Wie es aussieht

Farben, Schrift, Abstände. Sorgt dafür, dass die Seite auf dem iPad und am Smartboard passt.

JavaScript

Was passiert

Prüfen, zählen, mischen, Timer laufen lassen. Alles, was auf einen Klick reagiert.

Station 4 von 5 · Werkbank

Code einfügen, ansehen, sichern

1

Code holen

Zeigt die KI eine Vorschau (Canvas bei ChatGPT und Gemini, Artefakt bei Claude), klickst du die Seite dort schon durch. Sonst kopierst du den Code-Block.

2

Hier testen

Füge den Code links ein. Rechts siehst du die Seite in iPad-, Handy- oder Tafelbreite.

3

Als Datei sichern

Code am Rechner in einen Texteditor einfügen (Windows: Editor, Mac: TextEdit im Modus „reiner Text“) und als quiz-thema.html speichern. Wichtig ist nur die Endung .html. Dann ins Schulportal, auf die Edumap oder per Airdrop verteilen.

Station 5 von 5

Prüfen, bevor die Klasse sie bekommt

Die KI macht inhaltliche Fehler, gerade bei Quizlösungen. Den Fehler musst du nicht im Code suchen: beschreib einfach, was du siehst.

Checkliste

Reparatur-Sätze zum Kopieren

Antippen kopiert den Satz. Ergänze ihn mit dem, was genau falsch ist.

Grenzen einer einzelnen Datei

Ergebnisse bleiben am Gerät

Es gibt keinen Server. Wer Ergebnisse sehen will, lässt einen Ergebniscode oder Screenshot abgeben.

Keine echten Namen im Netz

Schülernamen und Noten gehören nie in eine hochgeladene Datei. Namen erst im Unterricht eintippen.

Klein schlägt groß

Eine Seite mit einer Aufgabe gelingt zuverlässig. Eine ganze Reihe in einer Datei wird fehleranfällig.

Bilder und Videos

Externe Bilder laden offline nicht. Lass die KI Grafiken lieber selbst zeichnen (SVG) oder Emojis weglassen.

Alle Demos laufen vollständig in deinem Browser. Nichts wird übertragen. Angelehnt an die HTML-Werkstatt von KILehrkraft.de, neu aufgebaut.
