🎮 Erstelle dein eigenes Lernspiel

Mit diesem Prompt baut dir eine KI (z. B. Claude oder ChatGPT) ein Lernspiel für deinen Unterricht – als einzelne HTML-Datei, die du überall einsetzen kannst.

  1. Prompt mit dem Button kopieren.
  2. In Claude oder ChatGPT in einen neuen Chat einfügen.
  3. Die Angaben in den [eckigen Klammern] anpassen: Fach, Jahrgang, Thema, Spieltyp, Spielmodus … Nicht Gewünschtes einfach löschen.
  4. Die KI stellt zuerst Rückfragen – beantworten, dann baut sie das Spiel.
  5. Die fertige .html-Datei speichern und öffnen oder hochladen, z. B. auf GitHub Pages.
