Promptlabor

Mit diesen Prompts baut dir eine KI (z. B. Claude oder ChatGPT) ein eigenes Lernspiel für deinen Unterricht – als einzelne HTML-Datei. Zu jedem Prompt gibt es ein Beispielspiel, das genau damit entstanden ist.

  1. Prompt mit dem Button kopieren.
  2. In Claude oder ChatGPT in einen neuen Chat einfügen.
  3. Die Angaben in den [eckigen Klammern] anpassen: Fach, Jahrgang, Thema … Nicht Gewünschtes einfach löschen.
  4. Rückfragen der KI beantworten, dann baut sie das Spiel.
  5. Die fertige .html-Datei speichern und öffnen oder hochladen, z. B. auf GitHub Pages.

Lernspiel für den Unterricht (Allround)

Quiz-Show, Wettrennen, Escape Room, Sportspiel … – du wählst Spieltyp, Modus und Aufgabenformate selbst. Auch mit Mehrspieler-Modus für die ganze Klasse.

Slash-Codes für ChatGPT: Meine visuellen Lerncodes

        
Einmal zu Beginn eines Chats einfügen. Danach reicht ein Code plus Thema, z. B. /mindmap Bruchrechnen Jg. 6, und ChatGPT setzt das passende Format um.

  • /timelineEreignisse oder Arbeitsschritte chronologisch auf einem Zeitstrahl

  • /flashcardsFrage-Antwort-Lernkarten mit Lösungen und steigender Schwierigkeit
