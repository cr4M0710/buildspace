▸ ANLEITUNG FÜR LEHRKRÄFTE

Vom Lehrplan zum Pixel-Rollenspiel

Du gibst einer KI deinen Lehrplanauszug – sie baut daraus ein kleines Rollenspiel im Browser: Figuren ansprechen, Gegenstände untersuchen, Fragen lösen. Dazu ein passendes Arbeitsblatt für die Sicherung. Hier steht, wie das zuverlässig klappt.

INHALT So sieht das Ergebnis aus Was du brauchst Beispiel-Prompt Prompt-Baukasten Ideen für andere Fächer So gehst du vor Wenn etwas hakt Vor dem Einsatz

01So sieht das Ergebnis aus

Eine einzige HTML-Datei, die auf jedem iPad im Browser läuft. Die Lernenden steuern eine Figur durch wenige Räume, sprechen mit Figuren und sammeln Hinweise, die sie zum Ziel führen. Wer eine Aufgabe richtig löst, kommt weiter. Probier die Mini-Vorschau aus:

Hinweis: Lauf mit den Pfeilen zur Händlerin und drück „Sprechen“.

Beispielthema aus Arbeitslehre (Jg. 7): Preise vergleichen auf dem Wochenmarkt. Ein ausgewachsenes Beispiel mit sechs Räumen ist Akte Wahrheit – 1938.

02Was du brauchst

Pflicht

Ein KI-Konto

Claude oder ChatGPT, am besten mit einem Modell, das längeren Code am Stück schreiben kann. Die kostenlosen Varianten reichen für kleine Spiele, brechen aber manchmal ab.

Pflicht

Deinen Lehrplanauszug

Zwei bis sechs Kompetenzen oder Inhalte aus dem Kerncurriculum bzw. Schulcurriculum – als Text kopiert, nicht als Foto.

Optional

Einen Ort zum Teilen

GitHub Pages, Netlify oder die Plattform deiner Schule. Ohne Hosting kannst du die Datei auch per AirDrop verteilen.

Zeit

30–60 Minuten

Erstes Ergebnis nach wenigen Minuten, danach zwei bis vier Runden Nachbessern und einmal selbst durchspielen.

03Beispiel-Prompt

So sieht ein vollständiger Prompt für das Wochenmarkt-Beispiel aus. Du kannst ihn direkt kopieren und ausprobieren.

Du bist Spieleentwickler:in und Lehrkraft zugleich. Baue ein kleines Lern-Rollenspiel im Pixel-Stil als EINE eigenständige HTML-Datei (HTML, CSS und JavaScript inline, keine externen Dateien, keine Bilder – alles mit Canvas oder CSS zeichnen). FACH UND KLASSE: Arbeitslehre, Jahrgang 7, IGS (heterogene Lerngruppe) LEHRPLANBEZUG: - Verbraucherinnen und Verbraucher vergleichen Preise und Qualität - Grundpreis (Preis pro kg/l) berechnen und vergleichen - Werbeaussagen kritisch prüfen SITUATION: Die Spielfigur hilft auf dem Wochenmarkt beim Einkauf für das Schulfest. Budget: 25 €. Drei Stände, eine Bäckerei und ein Infostand. SPIELABLAUF: 1. Startbildschirm mit Spielname, kurzer Story und „Los geht's“. 2. 3 kleine Räume (Kachelkarte 12×8), Wechsel über Türen/Ränder. 3. 4–6 Figuren mit kurzen Dialogen (2–4 Sätze), Antwortknöpfe zum Anklicken. 4. 8 Hinweise/Aufgaben, jede an Figur oder Gegenstand gebunden. Richtige Antwort → Hinweis ins Notizbuch. Falsche Antwort → freundliche Rückmeldung mit Tipp, erneuter Versuch. 5. Abschluss: 6 Fragen (Multiple Choice), Punktzahl, kurze Auswertung pro Frage. BEDIENUNG: Pfeiltasten/WASD und E; auf dem iPad große Richtungsknöpfe und Interaktionsknopf. Notizbuch jederzeit öffnen. SPRACHE: Deutsch, kurze Sätze, Sprachniveau für Klasse 7, Fachbegriffe einmal erklären. TECHNIK: Spielstand in localStorage speichern (mit try/catch). Keine Server, keine API-Aufrufe, keine Tracker. DAZU: Erstelle zusätzlich ein Arbeitsblatt (als druckbare HTML-Seite in einem zweiten Codeblock) mit 4 Aufgaben zur Sicherung und einer Lösung. Prüfe am Ende selbst: Ist jedes Rätsel lösbar? Gibt es genau eine richtige Antwort? Funktioniert die Steuerung per Touch?

04Prompt-Baukasten für dein Fach

Trag deine Angaben ein – der Prompt wird unten automatisch zusammengebaut. Nichts davon verlässt dieses Gerät.

05Ideen für andere Fächer

🧮 Mathematik

Baustelle: Flächen und Volumen ausrechnen, damit der Bauleiter die richtige Menge Beton bestellt.

🏛️ Geschichte / Gesellschaftslehre

Archiv-Ermittlung: Quellen prüfen, Perspektiven vergleichen, am Ende ein begründetes Urteil.

🧪 Naturwissenschaften

Forschungsstation: Messreihen auswerten und Hypothesen zu Licht, Wärme oder Pflanzen prüfen.

🇬🇧 Englisch

Stadtrundgang: Wegbeschreibungen verstehen und Figuren in der richtigen Zeitform antworten.

🔧 Arbeitslehre / Technik

Werkstatt-Check: Gefahren finden, Werkzeuge zuordnen, Sicherheitszeichen deuten.

💼 Berufsorientierung

Praktikumstag: In drei Betrieben Aufgaben lösen und am Ende ein passendes Berufsfeld begründen.

06So gehst du vor

  1. Neuen Chat öffnen und den Prompt aus dem Baukasten einfügen.
  2. Claude erstellt das Spiel als Artefakt – rechts erscheint direkt eine spielbare Vorschau.
  3. Selbst durchspielen, Fehler notieren und gesammelt zurückmelden („Der zweite Raum hat keine Tür“, „Frage 3 hat zwei richtige Antworten“).
  4. Nach jeder Änderung erneut testen – immer nur 2–3 Änderungen pro Nachricht.
  5. Fertige Datei herunterladen oder das Artefakt veröffentlichen und den Link teilen.
  6. Arbeitsblatt in einem zweiten Schritt anfordern: „Erstelle jetzt das Arbeitsblatt als Word-Datei.“
  1. Neuen Chat öffnen, Prompt einfügen und um eine einzige HTML-Datei bitten.
  2. Mit Canvas bekommst du eine Vorschau; sonst den Code kopieren, als spiel.html speichern und im Browser öffnen.
  3. Durchspielen und Fehler sammeln. Bricht der Code ab: „Schreibe ab der Funktion … weiter, gib den Rest vollständig aus.“
  4. Bei langen Spielen um die Datei als Download bitten, statt um einen Codeblock.
  5. Datei auf GitHub Pages, Netlify oder der Schulplattform ablegen.
  6. Arbeitsblatt anfordern und vor dem Druck fachlich prüfen.

07Wenn etwas hakt

Der Code bricht mittendrin ab

Schreibe: „Gib die komplette Datei erneut aus, ohne Kommentare und ohne Erklärtext.“ Oder verkleinere das Spiel (weniger Räume, kürzere Dialoge).

Die Figur läuft durch Wände oder bleibt hängen

„Prüfe die Kollisionsabfrage: Wände, Möbel und Figuren dürfen nicht betreten werden. Die Startposition muss frei sein.“

Auf dem iPad lässt sich nichts steuern

„Ergänze große Touch-Richtungsknöpfe (mind. 56 px) und einen Interaktionsknopf. Verhindere Doppeltipp-Zoom.“

Fachliche Fehler in den Aufgaben

KI irrt sich auch bei Fakten und Rechnungen. Lass dir eine Tabelle aller Fragen mit Lösung ausgeben und prüfe sie selbst, bevor du das Spiel einsetzt.

Der Spielstand ist nach dem Neuladen weg

„Speichere Fortschritt und Notizbuch in localStorage und stelle beides beim Start wieder her. Füge einen Knopf ‚Neu beginnen‘ hinzu.“

Das Spiel ist zu schwer oder zu leicht

„Erstelle eine zweite Schwierigkeitsstufe: kürzere Texte, Wortspeicher und ein Tipp-Knopf für Stufe 1; offene Eingaben für Stufe 2.“
